# Thesis Citation Checker

This project checks whether what a thesis says about each cited paper is correct, using the full
text of the PDFs as the only source of truth.

**Language:** talk to the user in the language set in `config.json` (`language`: `en` = English,
`es` = Spanish). Code, file names and data formats are always in English.

## Layout
- `config.json` — `language`, `papers_dir` (PDFs, subfolders included) and `thesis_dir` (a LaTeX project
  or a .docx/.md/.txt file), plus an optional `thesis_main`. The folders can be anywhere on disk; the user
  picks them in the viewer. **Never modify, move or rename anything inside those folders.**
- `extracted/` — generated by the scripts; do not edit by hand:
  - `papers/<key>.txt` — text of each PDF with `=== [p. N] ===` page markers.
  - `papers.json` — where each key's PDF lives (relative path, folder, pages, scanned flag).
  - `thesis.md` — the whole thesis in reading order (all `\input`/`\include`d files), paragraphs tagged
    `[P0001]`, with `<!-- file: ... -->` markers.
  - `thesis_structure.json` — included files, chapters/sections and their paragraph ranges; file and line of each paragraph.
  - `detected_citations.csv` — citations found automatically (a checklist).
- `claims/papers.csv` — key, file, folder, authors, year, title of each paper (`/cite-init` fills the metadata; the user may fix it).
- `claims/claims.csv` — one row per (thesis claim, cited paper). Maintained by `/cite-claims`.
- `claims/review.json` — the user's decisions and notes from the viewer. Do not modify.
- `results/<key>.json` — verdicts per paper. Written by the `verifier` subagent.
- `reports/` — `report.xlsx` and `report.md`, generated by `scripts/report.py`.
- `viewer/` + `scripts/viewer.py` — local page (http://localhost:8765): folder pickers, thesis and paper trees,
  results, Claude sign-in; it runs these commands through `claude -p`.
- `scripts/` — Python without AI: extraction, quote checking, status and reports.

## Workflow
1. `/cite-init` → read the papers and thesis folders, fill in `claims/papers.csv`.
2. `/cite-claims [section]` → record every cited claim in `claims/claims.csv`.
3. `/cite-verify pending|<key>|all|section X` → one `verifier` subagent per paper.
4. `/cite-report` → re-check quotes and rebuild reports. `/cite-review <id>` to discuss a case.
   `/cite-status` for progress. `/cite-viewer` to open the viewer.

## Rules
- The only source of truth is `extracted/papers/`. Never use prior knowledge about a paper.
- All evidence is a verbatim quote copied from the extracted text, in its original language, with its page.
  `scripts/check_quotes.py` checks it; a quote that is not found is treated as invented.
- One paper per subagent: the verifier sees only that paper and its claims, never the whole thesis.
- Suggested wordings in the thesis's language; verbatim quotes in the paper's language;
  explanations in the `config.json` language.
- Run scripts with `python` (or `python3` if `python` does not exist) from the project root.
- When launched from the viewer (non-interactive), do not ask questions: make the reasonable choice
  and explain it in the final summary.
- Never edit the user's thesis or papers; propose changes and let them decide.
